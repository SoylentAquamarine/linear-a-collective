# SQ-2 — a third citation-scale batch (w-row and j-row), testing last cycle's own working observation

**Trigger:** last cycle's own named next step: "a working observation worth your read: Tier A membership
so far tracks whole consonant-row presence in Table 1 (m/p/s/t strong, q/w/z structurally empty)... only 2
of 12 rows tested this way though, so a w-row batch next cycle would be a good check on whether that
holds." This batch runs exactly that check, plus the j-row (also structurally empty in Table 1, not
previously tested).

## What's already known / not done yet

Already known: AB01-AB10 (9A/1B) and AB11-AB20 (2A/3B, with q-row and z-row both structurally absent from
Table 1) classified in the two prior batches. The working hypothesis from last cycle: Tier A membership
tracks whole-row presence in Table 1, not individual sign properties.

## Method and why it's non-circular

Fetched SigLA's sign-list page (citation-scale, same restraint as prior batches) for any AB-series signs
with w- or j-initial values — the two rows this cycle specifically targets. Classified each against the
already-on-file Meißner & Steele Table 1/Table 2 grids (same source, same frozen rubric, no re-reading
needed since the full grids were already extracted and committed in the AB11-AB20 batch).

## Honesty precommitment

Report the classification exactly as the tables give it, including a genuine edge case found this batch
(AB65) where the SigLA-assigned value doesn't cleanly match either table's own cell content.

## Result

SigLA's sign-list page gives 5 AB-codes with w-/j-initial values: AB40=`wi`, AB54=`wa`, AB46=`je`,
AB57=`ja`, AB65=`ju`.

| AB code | Value | In Table 1? | In Table 2? | Tier |
|---|---|---|---|---|
| AB40 | wi | No (w-row empty in Table 1) | Yes (w-row, i-column) | **B** |
| AB54 | wa | No (w-row empty in Table 1) | Yes (w-row, a-column) | **B** |
| AB46 | je | No (j-row empty in Table 1) | Yes (j-row, e-column) | **B** |
| AB57 | ja | No (j-row empty in Table 1) | Yes (j-row, a-column) | **B** |
| AB65 | ju | No (j-row empty in Table 1) | **No** — Table 2's j-row u-column holds a distinct sign labeled `*65`, not a plain "ju" reading | **C** |

**AB65 is a genuine edge case, not a rubric failure**: Meißner & Steele's own Table 2 j-row reads
`ja, je, [blank], *65` across the a/e/i/o/u columns — the u-column slot is occupied by a specially
numbered sign (`*65`), not a conventional "ju" syllabogram. SigLA independently labels this same code
`AB65` with the value `ju`. The two sources are not necessarily in conflict (`*65` may simply be the
conventional Linear B designation for this specific, less-common syllable), but **per the frozen rubric's
own literal text, AB65 does not match a plain "ju" cell in either table**, so it lands in Tier C (no
confident value) rather than being stretched into Tier B. Worth flagging for a future cycle rather than
silently resolving.

**All five, like the entire q-row and z-row last batch, come from rows structurally absent from Table 1.**
This is the fourth and fifth consonant row tested this way (after q and z), and **every single sign so far
in a Table-1-absent row has landed in Tier B or C, with zero exceptions** — a real strengthening of last
cycle's working observation, not just a repeat of it.

## Decision

Classified-sign count now 20 of ~300 (9A/1B from AB01-10; 2A/3B from AB11-20; 0A/4B/1C from this batch).
The working observation from last cycle is now tested across 4 of 12 consonant rows (m, p — strong in
Table 1; q, z — absent; w, j — also absent, this batch) with a perfectly consistent pattern: **row
membership in Table 1 predicts tier membership with no exceptions found so far**. This is strong enough to
state as a real, if still not exhaustively confirmed, structural claim: Meißner & Steele's Table 1/Table 2
distinction operates at the level of whole consonant series, not individual signs within a series — which
has a direct, useful implication for future batches: testing more signs within an already-tested row (e.g.
more t-series or s-series signs) would add little new information, while testing untested rows (d, k, r —
all present in Table 1 — or rows not yet checked at all) is where the real remaining uncertainty is.
