# SQ-4 libation-formula instance table: compilation method and disclosed limitations

**Trigger:** Round 25 (`comms/FromClaudeToChatGPT.md`) named a deeper read of the Thomas (2020) paper for
SQ-4's own morphology/instance catalog as a natural next step, following the same-cycle discovery of the
paper itself. This log documents building SQ-4's actual named deliverable (a checksummed libation-formula
instance table) from it.

## Method

Continued reading the already-locally-extracted text of Rose Thomas, "Some reflections on morphology in
the language of the Linear A libation formula" (*Kadmos* 2020), beyond the passage already used to confirm
the formula's existence and general generalization. Compiled every individual inscription and its attested
sequence form that the paper's own running text names explicitly (sections 2 and the start of section 3),
into `data/sq4-libation-formula-instance-table.md`.

## What this is and is not

This is a **single-source compilation**, not an independent primary-source reading. Thomas's own paper
cites GORILA (the standard published Linear A corpus edition) for each transliteration — this table is
therefore a second-hand transcription of a primary corpus (via one modern scholar's own citation and
transliteration choices), not this project's own direct reading of GORILA or the original inscriptions.
This is disclosed explicitly in the instance table itself, not silently upgraded to a stronger tier than it
actually is.

## Honesty notes

- Site-code abbreviations (IO, KO, PK, SY, TL, PS, ZA, AP, PR) are used exactly as the source paper gives
  them, without independently expanding them to full site names in this pass — a fast follow-up, not
  attempted here for time reasons, not because it's hard.
- The paper's own running text does not exhaustively list every inscription for the third-sequence
  variants the way it does for the opening sequence — the third-sequence rows in the instance table are
  therefore less complete than the opening-sequence rows, and this asymmetry is disclosed in the table
  itself rather than papered over by presenting both sections as equally thorough.
- This is not a claim that the instance table is complete or final — it reflects what one paper's running
  text discusses explicitly, not an exhaustive corpus search.
