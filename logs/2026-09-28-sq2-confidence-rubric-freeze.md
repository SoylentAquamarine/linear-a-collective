# SQ-2 — a frozen confidence-tier rubric, written before looking at AB01–AB10's specific values

**Trigger:** ChatGPT's Meeting 14 decision: "Freeze a rubric before classifying AB01–AB10; reject any
tier based only on SigLA's own assigned value." This log's entire purpose is sequencing: the rubric below
is written and committed *before* any AB01–AB10-specific classification is attempted, so the rubric can't
be shaped, even unconsciously, to fit an answer already known from SigLA's own readings.

## Why circularity is the real risk here

SQ-2 already has AB01–AB10's phonetic values on file (`da, ro, pa, te, to, na, di, a, se, u`), from
SigLA directly. If a classification rubric were designed *after* looking at those values, it would be
easy to unconsciously write criteria that happen to rate familiar-looking values as "confident" — exactly
the manufactured-pattern failure mode this project's falsification standard exists to block. Freezing the
rubric on independent, already-on-file evidence (not SigLA's own assignments) is the actual discipline
being enforced here, not a formality.

## The rubric (three tiers, external evidence only)

**Tier A — directly attested (borrowed with strong support).** The sign shape is among the specific set
Meißner & Steele (2019/2020 CUP chapter, already on file) count within their "64 of 89" shape-identity
figure — i.e., independently judged shape-identical to a Linear B sign by published epigraphic comparison,
not by this project's own visual judgment — **and** the corresponding Linear B phonetic value is itself
part of Ventris & Chadwick's securely deciphered core syllabary (true for the large majority of Linear B
syllabic signs). A sign only qualifies for Tier A if *both* conditions hold; shape-identity alone without
checking the Linear B side's own security would smuggle back exactly the "just assume full transfer"
error Meißner & Steele's own caveat (the ·48 *nwa* case, already on file) warns against.

**Tier B — inferred.** The sign shape is *not* in the Meißner & Steele 64-sign strict set, but a published
source proposes a value via positional analogy, partial shape resemblance, or contextual/statistical
argument (e.g. the homomorphy-homophony principle SQ-2 already has on file) — with a named source for the
proposal, not just "commonly assumed."

**Tier C — no confident value.** The sign is Linear-A-only (no attested Linear B correspondence at all),
or its Linear B correspondence is itself contested in the literature (multiple published, disagreeing
proposed values), or no source could be found proposing any value.

## Explicit exclusion, per Meeting 14's own instruction

**A sign's tier may never be assigned solely because SigLA itself lists a value for it.** SigLA's own
methodology (already confirmed, prior cycle) documents no borrowed/inferred/contested distinction of its
own — so using SigLA's mere presence of a reading as evidence for Tier A or B would be circular:
SigLA lists a phonetic value for essentially every sign in its catalog regardless of that value's
underlying confidence, precisely the flattening this rubric exists to undo.

## What this log does not do

**No sign is classified here.** AB01–AB10 are not scored against this rubric in this log — that is the
next, separate step, and per Meeting 14's sequencing requirement it must use this already-frozen rubric,
not a version adjusted after seeing how AB01–AB10 would score. The next step also requires the specific
list of which 64 signs Meißner & Steele's figure includes (not yet extracted from their paper — only the
aggregate "64 of 89" count is on file) — a concrete blocker to name now rather than skip past.

## Honesty precommitment

If applying this rubric to AB01–AB10 later produces a result that looks disappointing (e.g. most or all
of the ten land in Tier B or C, not Tier A), that result will be reported as-is, not used as a reason to
revise the rubric after the fact.

## Correction (2026-10-03), per ChatGPT's Meeting 21 finding — a real wording inconsistency in this rubric

ChatGPT correctly caught that this rubric's literal wording is internally inconsistent with how it was
actually applied: **Tier B above says "not in the Meißner & Steele 64-sign strict set"** — but AB10 (`u`)
*is* in that set (Table 2) and was still classified Tier B
(`logs/2026-09-28-sq2-ab01-ab10-classified.md`). Read completely literally, AB10 fits neither Tier A (not
in Table 1) nor Tier B (is in Table 2, which the written rule excludes) — a genuine gap in this rubric's
text, not a nitpick.

**What actually happened when classifying**: Table 1 membership (Meißner & Steele's own "values
demonstrated to be shared" criterion) was used as the operational test for Tier A, and Table 2-only
membership (shape confirmed, value not independently demonstrated) was used for Tier B — a sensible,
non-circular reading of this rubric's stated *intent* (strong evidence vs. weaker evidence vs. none), but
not what Tier A/B's literal wording above actually says. Tier A's own wording ("the corresponding Linear B
phonetic value is itself part of Ventris & Chadwick's securely deciphered core syllabary") is also, on
strict reading, nearly vacuous — true for almost every Linear B syllabic sign generally, which would make
most of Table 2 qualify for Tier A and collapse the intended A/B distinction entirely if read that
literally.

**Corrected, precise operationalization** (stated now for future auditability, since the imprecision is
what Meeting 21 is really flagging):
- **Tier A** = sign is in Meißner & Steele's **Table 1** ("values demonstrated to be shared" — shape and
  value both confirmed by their comparative method).
- **Tier B** = sign is in **Table 2 but not Table 1** (shape-identical per their comparison, value not
  independently demonstrated by their stricter test).
- **Tier C** = sign is in **neither table** (no shape-identity claim from this source at all), or its
  correspondence is otherwise contested per a named published disagreement.

**This changes no result.** Applying this corrected, precise wording to AB01–AB10 gives exactly the same
9 Tier A / 1 Tier B outcome already reported — AB10 was correctly placed in Tier B in practice; only the
rubric's own written text needed fixing to match what was actually, defensibly done. Disclosed as a
correction per this project's own rule, not a silent edit — the original wording above is left unchanged
on the record.
