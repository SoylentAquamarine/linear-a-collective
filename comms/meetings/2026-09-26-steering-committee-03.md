# Steering Committee Meeting 3 — 2026-09-26

## Evidence and goal

The source behind the 72% figure is now directly read: 64 of 89 reference signs are judged shape-identical between Linear A and Linear B. This is visual correspondence, not phonetic confidence or translation.

## Falsification, ethics, and permissions

Transferred sound values must be classified sign by sign and fail if they do not generalize across contexts. SigLA's CC BY-NC-SA terms must be preserved in any derived dataset.

## Blockers, compute, and website

The missing deliverable is a scoped SigLA retrieval and confidence table. This is a data-steward task suited to deterministic worker time after the retrieval scope is authorized. The homepage still says there are no findings.

## Decision and measurable improvement

Start with a bounded pilot of 20 frequent shared signs, recording shape identity, proposed Linear B value, Linear A evidence, and confidence. Measure improvement by inter-reviewer agreement and by explicit unknowns, not the number of values assigned.
